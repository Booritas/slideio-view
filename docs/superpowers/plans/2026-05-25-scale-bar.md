# Scale bar implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a graphical scale bar above the magnification slider in the existing `ZoomIndicatorWidget` overlay, showing the slide's physical scale in micrometers — visible only when the slide reports a valid pixel resolution.

**Architecture:** Pure-C++ helper `pickScaleBarLength` in `slideio-viewer-core` (Qt-free, unit-tested with Catch2) chooses a 1/2/5-series "nice" length whose screen width fits a budget. A new `ScaleBarWidget` (`slideio-viewer-ui`) renders the bar via `QPainter` and is composed as a child of `ZoomIndicatorWidget`. `MainWindow` forwards `SlideInfo::resolutionX` on `slideOpened`/`slideClosed`; the existing `viewportChanged → setZoomLevel` path already relabels the bar on zoom.

**Tech Stack:** C++17, Qt 6 Widgets, Catch2 (tests), CMake 3.20+, Conan, MSVC 2022 (Visual Studio 17 generator on Windows).

**Reference spec:** `docs/superpowers/specs/2026-05-25-scale-bar-design.md`

**Project convention:** Per user preference (`feedback_workflow_main_branch.md`), features land as a series of direct commits to `main`. Each task ends with its own commit. No branches, no PRs.

```cpp
#pragma once

namespace slideio::viewer::core
{

struct ScaleBarTick
{
    double lengthMicrons = 0.0;  // 0.0 when input is invalid (caller hides bar)
    int    pixelWidth    = 0;    // matching screen pixels, rounded
};

/// Pick the largest "nice" length (1/2/5 series) whose screen width does not
/// exceed maxBarPixels. Returns {0, 0} only when micronsPerPixel <= 0.
/// If even the smallest candidate (0.1 um) overflows maxBarPixels, that
/// smallest candidate is still returned and pixelWidth may exceed maxBarPixels —
/// callers may clamp visually as they see fit.
ScaleBarTick pickScaleBarLength(double micronsPerPixel, int maxBarPixels);

} // namespace slideio::viewer::core
```

- [ ] **Step 2: Write the implementation**

Write `src/core/src/ScaleBar.cpp`:

```cpp
#include "slideio/viewer/core/ScaleBar.h"

#include <cmath>

namespace slideio::viewer::core
{

namespace
{

// 1/2/5 series in micrometers, monotonically increasing.
constexpr double kCandidateLengthsMicrons[] = {
    0.1, 0.2, 0.5,
    1.0, 2.0, 5.0,
    10.0, 20.0, 50.0,
    100.0, 200.0, 500.0,
    1000.0, 2000.0, 5000.0,
    10000.0, 20000.0, 50000.0,
    100000.0,
};

} // namespace

ScaleBarTick pickScaleBarLength(double micronsPerPixel, int maxBarPixels)
{
    if (micronsPerPixel <= 0.0) {
        return {0.0, 0};
    }

    // Walk candidates from largest to smallest; pick the first whose width fits.
    for (auto it = std::rbegin(kCandidateLengthsMicrons);
         it != std::rend(kCandidateLengthsMicrons); ++it) {
        const double widthPx = *it / micronsPerPixel;
        if (widthPx <= static_cast<double>(maxBarPixels)) {
            return { *it, static_cast<int>(std::round(widthPx)) };
        }
    }

    // Even the smallest candidate overflows maxBarPixels — return it anyway,
    // with its actual (overflowing) pixel width. Per spec, the caller decides
    // what to do; in practice this branch is unreachable for the zoom range
    // the magnification slider exposes.
    const double smallest = kCandidateLengthsMicrons[0];
    return { smallest, static_cast<int>(std::round(smallest / micronsPerPixel)) };
}

} // namespace slideio::viewer::core
```

```cpp
#pragma once

#include <QWidget>

namespace slideio::viewer::ui
{

class ScaleBarWidget : public QWidget
{
    Q_OBJECT

public:
    explicit ScaleBarWidget(QWidget* parent = nullptr);
    ~ScaleBarWidget() override;

    /// metersPerPixelNative: SlideInfo::resolutionX (level 0 pixel size).
    /// viewportScale:        viewport.scale() (1.0 = native).
    /// Either <= 0 hides the widget; otherwise the widget is visible and repaints.
    void setScale(double metersPerPixelNative, double viewportScale);

protected:
    void paintEvent(QPaintEvent* event) override;

private:
    double m_metersPerPixelNative = 0.0;
    double m_viewportScale        = 0.0;

    // Half the QSlider handle width (see ZoomIndicatorWidget stylesheet: handle
    // "width: 12px; border-radius: 6px"). Aligns the bar with the slider groove.
    static constexpr int kHandleInset = 6;
    static constexpr int kBarY        = 4;   // y-position of the line
    static constexpr int kCapHalfLen  = 3;   // end caps span [kBarY-3, kBarY+3]
    static constexpr int kLabelGap    = 6;   // px between line and label top
    static constexpr int kLabelHeight = 14;  // px reserved for the label
};

} // namespace slideio::viewer::ui
```

- [ ] **Step 2: Write the implementation**

Write `src/ui/src/ScaleBarWidget.cpp`:

```cpp
#include "slideio/viewer/ui/ScaleBarWidget.h"

#include "slideio/viewer/core/ScaleBar.h"

#include <QFont>
#include <QPaintEvent>
#include <QPainter>
#include <QPen>
#include <QString>

namespace slideio::viewer::ui
{

namespace
{

QString formatLabel(double lengthMicrons)
{
    // Sub-um lengths get one decimal; whole-um lengths print as integer.
    if (lengthMicrons < 1.0) {
        return QString::fromUtf8("%1 \xC2\xB5m")
            .arg(lengthMicrons, 0, 'f', 1);
    }
    return QString::fromUtf8("%1 \xC2\xB5m")
        .arg(lengthMicrons, 0, 'f', 0);
}

} // namespace

ScaleBarWidget::ScaleBarWidget(QWidget* parent)
    : QWidget(parent)
{
    setAttribute(Qt::WA_TranslucentBackground);
    setFixedHeight(kBarY + kCapHalfLen + kLabelGap + kLabelHeight + 1); // 28 px
}

ScaleBarWidget::~ScaleBarWidget() = default;

void ScaleBarWidget::setScale(double metersPerPixelNative, double viewportScale)
{
    m_metersPerPixelNative = metersPerPixelNative;
    m_viewportScale        = viewportScale;

    const bool valid = metersPerPixelNative > 0.0 && viewportScale > 0.0;
    setVisible(valid);
    if (valid) {
        update();
    }
}

void ScaleBarWidget::paintEvent(QPaintEvent* /*event*/)
{
    if (m_metersPerPixelNative <= 0.0 || m_viewportScale <= 0.0) {
        return;
    }

    const double micronsPerScreenPixel =
        m_metersPerPixelNative * 1.0e6 / m_viewportScale;

    const int maxBarPx = width() - 2 * kHandleInset;
    if (maxBarPx <= 0) {
        return;
    }

    const auto tick = core::pickScaleBarLength(micronsPerScreenPixel, maxBarPx);
    if (tick.lengthMicrons <= 0.0 || tick.pixelWidth <= 0) {
        return;
    }

    const int x0 = kHandleInset;
    const int x1 = x0 + tick.pixelWidth;

    QPainter painter(this);
    painter.setRenderHint(QPainter::Antialiasing, false); // crisp 1px lines

    QPen pen(QColor("#CCCCCC"));
    pen.setWidth(1);
    painter.setPen(pen);

    // Horizontal line.
    painter.drawLine(x0, kBarY, x1, kBarY);

    // End caps.
    painter.drawLine(x0, kBarY - kCapHalfLen, x0, kBarY + kCapHalfLen);
    painter.drawLine(x1, kBarY - kCapHalfLen, x1, kBarY + kCapHalfLen);

    // Label centered under the bar.
    QFont labelFont = painter.font();
    labelFont.setPixelSize(10);
    painter.setFont(labelFont);

    const QString text  = formatLabel(tick.lengthMicrons);
    const int labelY    = kBarY + kCapHalfLen + kLabelGap;
    const QRect textRect(x0, labelY, x1 - x0, kLabelHeight);
    painter.drawText(textRect, Qt::AlignHCenter | Qt::AlignTop, text);
}

} // namespace slideio::viewer::ui
```

## Task 7: Manual verification

No automated test framework covers the UI; this task is a structured manual smoke test before declaring the feature done. Use a slide with known resolution (e.g. any SVS/CZI/NDPI in the team's test corpus).

- [ ] **Step 1: Launch the viewer**

Run the built executable (path depends on install layout):
- `./install/bin/slideio-viewer.exe` (after `./build.sh`), or
- `./build/build/bin/Release/slideio-viewer.exe` (direct from build tree, if `CMAKE_RUNTIME_OUTPUT_DIRECTORY` so configures it).

If neither exists, run `./build.sh` first.

- [ ] **Step 2: Open a slide with resolution**

Use **File → Open Slide…** and open a brightfield WSI with a known resolution (e.g. an Aperio SVS file). Confirm:
- The scale bar appears in the zoom-indicator overlay (top-right of the viewport).
- The bar is between the magnification/percentage labels and the slider.
- The bar has visible end caps.
- The label below the bar shows a sensible round number with `µm` suffix (e.g. `100 µm`, `500 µm`).
- The bar's pixel length is consistent with the label (estimate visually — at 40× a 100 µm bar should look like ~80 px).

- [ ] **Step 3: Pan and zoom**

- **Pan** (left-click drag): the bar label does **not** change.
- **Zoom in** (mouse wheel or slider): the bar discrete-snaps to a smaller length (e.g. 500 µm → 200 µm → 100 µm → 50 µm → ...). It never extends beyond the slider's groove on the right.
- **Zoom out** (opposite): the bar discrete-snaps to a larger length (100 µm → 200 µm → 500 µm → 1000 µm → ...).

- [ ] **Step 4: Open a resolution-less slide**

If you have an asset with no resolution metadata (or temporarily zero out the resolution in the file), open it and confirm:
- The scale bar widget is **hidden** — the zoom indicator shows only the magnification labels and slider, with a small gap where the bar would have been.
- The zoom slider still works.

If you can't easily produce such a file, manually verify by setting a breakpoint in `MainWindow::slideOpened` and forcing `info.resolutionX = 0.0;` before the `setResolution` call.

- [ ] **Step 5: Close and reopen**

**File → Close Slide**: the bar disappears (along with the rest of the viewer's slide state).
**File → Open Slide…** (a resolved slide): the bar reappears with a sensible length.

- [ ] **Step 6: Switch scenes / Z / T (if applicable)**

If the slide has multiple scenes, Z-slices, or T-frames, switch between them and confirm the bar does not flicker, relabel, or disappear (resolution doesn't change across Z/T, so the label should be stable).

- [ ] **Step 7: Final commit (optional)**

No code changes from this task — if any manual issues were discovered, capture them as follow-up tasks instead of patching silently. If everything works as specified, no commit is needed.
